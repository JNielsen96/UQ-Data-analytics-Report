<h1> UQ Data Analytics Report </h1>


<h2>Description</h2>
A designed experimental study (STAT1201 Research Project) investigating whether beer consumption affects athletic reaction time, using a 2×2 factorial design (alcohol: yes/no × sex: male/female) with 46 athlete participants. Reaction time was measured pre- and post-consumption via a ruler drop test, with the response variable defined as the before/after difference. Two-way ANOVA was used to test for main effects and an interaction between alcohol and sex, supported by an interaction plot, boxplots, and residual diagnostics (Q-Q plot and histogram of residuals) to confirm the normality assumption. Results showed no statistically significant effect of alcohol or sex on reaction time (all p > 0.05), with the discussion covering study limitations (small sample size, single reaction-time measure) and recommendations for future research.
